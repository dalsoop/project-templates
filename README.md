# 인포커터

개발할 때는 `./infocutter`만 씁니다.

## 커맨드

- `./infocutter dev`
- `./infocutter doctor`
- `./infocutter build`
- `./infocutter watch`
- `./infocutter check`
- `./infocutter rc`
- `./infocutter reset`

## 크롬 로드

1. `./infocutter dev`
2. `chrome://extensions`
3. 개발자 모드 켜기
4. `Load unpacked`
5. `dist` 폴더 선택

## 메모

- npm 스크립트는 내부 파이프라인용입니다.
- 바깥에서는 `./infocutter ...`만 쓰면 됩니다.
